# Recette en jeu — Jalon J6 (armement, munitions, armures balistiques, donjon à clé et gardien, caisse militaire, contrats de palier 3)

Prérequis : recettes J1 à J5 validées ; **un serveur dédié réel** (`./gradlew runServer` ou le `.jar` de la CI) : les GameTests n'ont ni client ni monde de jeu réel, donc la génération du donjon, les tirs et les écrans se vérifient ici. **Deux clients** pour les lignes marquées [2 joueurs] ; le même `.jar` (0.6.0-j6) sur le serveur et sur chaque client. Utiliser un **monde J5 existant** (copie du dossier du monde du serveur J5, ouvert avec le `.jar` J6). Joueur A : Chef de la nation « Aurore » et opérateur ; joueur B : membre d'Aurore, non opérateur sauf indication. Valeurs citées = configuration par défaut (section `[dungeon]`). Les blocs et objets du J6 n'ont pas encore de modèle ni de texture (lot graphique en attente) : un objet qui s'affiche avec le modèle manquant n'est pas un échec, et le gardien a l'apparence d'un zombi.

Pour aller vite, en opérateur (Tab complète les arguments) :
- Recherche : `/sfadmin research Aurore complete <palier>` (un palier à la fois, sans prérequis ni coût) ;
  `/sfadmin money give <joueur> <montant>` · `/sfadmin treasury Aurore <montant>` · `/sfadmin bypass`.

  | Palier | Clé(s) accordée(s) |
  |---|---|
  | `militaire_1` | `station.armament` (onglet Armement) |
  | `militaire_2` | `ammo.basic` |
  | `militaire_3` | `weapon.pistol` |
  | `militaire_4` | `armor.ballistic_light` |
  | `militaire_5` | `weapon.rifle` |
  | `militaire_7` | `ammo.piercing` |
  | `militaire_9` | `armor.ballistic_heavy` |
  | `militaire_10` | `weapon.sniper` |
  | `militaire_11` | `weapon.explosives` |
  | `militaire_12` | `ammo.sulfur` (requis aussi par le contrat palier 3, section K) |

  Les paliers `militaire_6`, `militaire_8` et `militaire_15` débloquent `defense.*` : sans effet au J6, ne pas les tester.
- Objets : `/give @s sovereignfrontier:<objet> [n]` (`pistolet`, `fusil`, `fusil_precision`, `explosif`, `munitions_basiques`,
  `munitions_perforantes`, `munitions_soufre`, `armure_balistique_legere`, `armure_balistique_lourde`, `trousse_soins`,
  `cle_donjon`, `autel_donjon`, `caisse_militaire`, `cle_militaire`, `lingot_titane`, `soufre`). Le fusil de précision ne
  se fabrique pas : `/give` est le seul moyen de le tester.
- Caisses : `/sfadmin crate givekey <joueur> militaire [n]` · `/crate preview militaire` (en jeu).
- Contrats : `/sfadmin contract Aurore refresh` · `complete <n>` · `expire <n>`.
- Mesurer les PV : `/data get entity @e[type=minecraft:creeper,limit=1,sort=nearest] Health` (la valeur apparaît dans le chat).
- Cible immobile, sans armure : `/summon minecraft:creeper ~ ~ ~10 {NoAI:1b}` (20 PV, ne bouge pas, n'explose pas) ; se
  placer face à elle, sur un sol plat.
- Gardien : `/kill @e[type=sovereignfrontier:gardien_donjon]` (mort réelle : la récompense est versée).
- Configuration (`<monde>/serverconfig/sovereignfrontier-server.toml`, section `[dungeon]`) : `altarCooldownHours = 0` pour
  les essais de recharge, puis remettre `6`. Si la valeur n'est pas prise en compte, redémarrer le serveur.

Coche chaque ligne ; note le message exact si un résultat diffère.
