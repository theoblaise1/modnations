# Recette en jeu — Jalon J1 (nation, grades, trésorerie, territoire)

Prérequis : `./gradlew runClient` (solo/LAN) **et** un test sur serveur dédié
(`./gradlew runServer` + 2 clients, ou le `.jar` de la CI sur ton serveur NeoForge 21.1.219+).
Pour accélérer : dans `serverconfig/sovereignfrontier-server.toml`, mettre
`incomeIntervalTicks = 200` et `cropYieldBonus = 1.0` (rechargé à chaud), puis remettre les valeurs.

Coche chaque ligne ; note le message exact si un résultat diffère.

## A. Démarrage
- [ ] A1. Le serveur dédié démarre sans erreur avec le mod (aucune `ClassNotFound`/`invalid dist`).
- [ ] A2. Première connexion : message « Compte ouvert : 1 000 cr », `/balance` affiche 1 000 cr.
- [ ] A3. L'onglet créatif « Sovereign Frontier » contient les 4 blocs, textures visibles, infobulles en français.
- [ ] A4. Les 4 recettes fonctionnent à l'établi (Trésor, Blindage ×4, Coffre, Registre).

## B. Fondation et territoire
- [ ] B1. `/nation create Alpha` → succès, annonce à tous, le chunk courant devient la capitale (`/map` : `■` vert sous vous).
- [ ] B2. `/nation create Beta` par un 2e joueur **dans le chunk d'Alpha** → refus explicite ; ailleurs → succès.
- [ ] B3. Nom invalide (`/nation create a`, `/nation create Été`) → message d'erreur clair.
- [ ] B4. Poser un Trésor national dans la capitale, clic droit → l'écran s'ouvre sur l'onglet Trésor, boutons actifs.
- [ ] B5. Déposer 500 → portefeuille 500, trésorerie 500, entrée dans le journal.
- [ ] B6. `/claim` dans un chunk voisin → débite **108 cr** ; le suivant **117 cr** ; un chunk non adjacent → refus « doit toucher ».
- [ ] B7. Trésorerie insuffisante → refus indiquant le coût et le solde.
- [ ] B8. Onglet Territoire (N) : carte 15×15, clic gauche sur un chunk libre adjacent = claim, clic droit sur un chunk à soi = abandon, infobulle au survol.
- [ ] B9. Messages en barre d'action en entrant/sortant du territoire (« ⚑ Territoire de Alpha » / « Terres sauvages »).
- [ ] B10. `/unclaim` sur un chunk à soi → succès ; sur un chunk d'une autre nation → refus.

## C. Membres, rôles, permissions
- [ ] C1. `/nation invite <J2>` (Tab propose les joueurs **sans nation**) → J2 reçoit un message avec **[Rejoindre]** cliquable.
- [ ] C2. J2 clique → rejoint en Recrue ; annonce aux membres ; `/nation info` liste les membres et rôles.
- [ ] C3. J2 (Recrue) `/claim` → refus « permission Revendiquer un chunk ».
- [ ] C4. Chef : onglet Rôles, clic sur la case Recrue × Revendiquer → passe au vert ; J2 peut maintenant `/claim`.
- [ ] C5. J2 ne peut pas modifier la matrice (cases non cliquables, mention « seul le chef »).
- [ ] C6. `/nation role <J2> officier` (Tab propose membres et rangs) → J2 Officier ; la même commande relancée → « déjà Officier », sans annonce ni entrée de journal.
- [ ] C7. J2 tente `/nation kick <Chef>` → refus (rang insuffisant) ; Chef `/nation kick <J2>` → J2 exclu et prévenu.
- [ ] C8. Chef `/nation leave` → refus explicite ; `/nation transfer <J2>` → J2 devient Chef, l'ancien chef Ministre.
- [ ] C9. Retrait au Trésor par un rang sans `retirer` → bouton grisé / refus ; avec la permission → OK.
- [ ] C10. `/nation log` et onglet Journal : création, invitation, adhésion, exclusion, transfert, claims, dépôts, retraits, changements de permission (50 max, plus récents en premier).

## D. Protection du territoire
- [ ] D1. Un joueur d'une autre nation (ou sans nation) ne peut ni casser, ni poser, ni ouvrir coffres/portes, ni vider un seau dans votre territoire (message en barre d'action).
- [ ] D2. Un membre dont le rang n'a pas `construire` est bloqué de la même façon.
- [ ] D3. Une explosion (TNT/creeper) en territoire ne détruit aucun bloc.
- [ ] D4. La nuit, aucun monstre n'apparaît naturellement en surface dans vos chunks (ils apparaissent toujours dans les grottes profondes et hors territoire).
- [ ] D5. Deux membres de la même nation ne peuvent pas se blesser.
- [ ] D6. Avec `cropYieldBonus = 1.0` : du blé mûr récolté en territoire donne environ le double ; hors territoire, rendement normal.
- [ ] D7. `/sfadmin bypass` (op) permet de construire partout ; le relancer le désactive.

## E. Coffre national
- [ ] E1. Coffre posé sans socle → refus « structure incomplète » ; sur un socle 3×3 de Blindage → ouverture (54 cases, titre « Coffre national — Alpha »).
- [ ] E2. Deux coffres nationaux de la même nation montrent **le même contenu**, y compris ouverts simultanément par deux joueurs.
- [ ] E3. Un rang sans `coffre` → refus ; un étranger → refus.
- [ ] E4. Le contenu survit à un redémarrage du serveur ; `/nation disband confirm` est refusé tant que le coffre n'est pas vide.

## F. Population et revenu
- [ ] F1. Maison : pièce close et couverte avec lit + porte, Registre civil à l'intérieur, clic droit → « Maison valide » et +1 habitant.
- [ ] F2. Atelier (établi + four + porte, sans lit) et ferme (≥ 16 terres labourées du territoire autour du registre, en plein air ou dans une serre close) reconnus.
- [ ] F3. Toit percé / porte retirée → message expliquant la cause (avec la position du trou).
- [ ] F4. Deux registres dans la même pièce → le second est refusé ; deux maisons enregistrées dont on casse le mur commun → une seule conservée à la revalidation suivante.
- [ ] F5. Casser un registre → bâtiment retiré, annonce aux membres ; un bâtiment détruit est retiré dans les ~minutes suivantes (revalidation tournante).
- [ ] F6. Avec `incomeIntervalTicks = 200` : la trésorerie reçoit `habitants × 5 cr` toutes les 10 s, message aux membres ; un écran national resté ouvert affiche le nouveau solde dans la seconde.
