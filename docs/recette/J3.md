# Recette en jeu — Jalon J3 (énergie, machines, réacteur, Station d'ingénierie)

Prérequis : recettes J1 et J2 validées ; une nation. Pour aller vite, en opérateur :
`/sfadmin research <nation> complete <palier>` pour `ressources_1`, `industrie_1` à `industrie_5`,
`ressources_8`, `industrie_7`, `industrie_10`, puis les prérequis de `technologie_1`.
Valeurs citées = configuration par défaut (section `[energy]`).

Coche chaque ligne ; note le message exact si un résultat diffère.

## A. Station d'ingénierie
- [ ] A1. Craft vanilla : `fer fer fer / cuivre établi cuivre / fer bloc_de_redstone fer` → Station d'ingénierie.
- [ ] A2. Clic droit → écran à 3 onglets (Machines, Armement, Aérospatial) ; liste des recettes, ingrédients avec quantité possédée (vert/rouge).
- [ ] A3. Sans la recherche correspondante → recette grisée ; « Fabriquer » refusé : « Recette verrouillée : votre nation doit d'abord terminer la recherche correspondante. »
- [ ] A4. Recette débloquée, ingrédient manquant → « Il manque N × objet dans votre inventaire. »
- [ ] A5. Fabrication réussie → ingrédients retirés de l'inventaire, « Fabriqué : … » ; `cable_energie` en donne 8.
- [ ] A6. S'éloigner à plus de 8 blocs de la station puis cliquer « Fabriquer » → refus « Ouvrez une Station d'ingénierie… ».
- [ ] A7. Terminer un palier pendant que l'écran est ouvert → la recette se déverrouille sans le rouvrir.

## B. Câbles et réseau
- [ ] B1. Les câbles se connectent visuellement entre eux et aux machines, pas aux blocs ordinaires.
- [ ] B2. Générateur thermique + câbles + cellule d'énergie : la cellule se charge (barre du GUI).
- [ ] B3. Ajouter une foreuse sur le même réseau : elle est servie **avant** la cellule ; la cellule ne se charge qu'avec le surplus.
- [ ] B4. Couper un câble → la partie déconnectée cesse d'être alimentée ; le reposer → reprise immédiate.

## C. Générateurs et stockage
- [ ] C1. Thermique : charbon dans l'emplacement → 20 En/t, barre de combustion ; sans combustible, la production s'arrête.
- [ ] C2. Solaire : 8 En/t de jour sous ciel ouvert ; 0 la nuit, sous la pluie ou sous un bloc.
- [ ] C3. Cellule d'énergie : 200 000 En max, 400 En/t en entrée et sortie ; elle alimente une foreuse quand les générateurs sont éteints.
- [ ] C4. Casser une machine chargée → contenu des emplacements lâché au sol ; l'énergie stockée est perdue.

## D. Foreuse à gaz
- [ ] D1. Bouteilles vides en entrée, foreuse alimentée → bouteilles pleines en sortie ; le GUI affiche la réserve restante de la dimension.
- [ ] D2. Sans énergie → aucune extraction.
- [ ] D3. Réserve finie : `gasPerDimension = 100` dans la config → la foreuse s'arrête une fois épuisée, réserve 0 affichée ; chaque dimension a sa propre réserve ; la réserve survit au redémarrage.

## E. Réacteur nucléaire
- [ ] E1. Construire une coque 5×5×5 de caissons, contrôleur au centre d'une face (face avant vers l'extérieur), intérieur : cellules de combustible, dissipateurs ou air → le GUI indique « structure valide » (vérifiée toutes les 2 s).
- [ ] E2. Retirer un caisson → structure invalide, plus de production.
- [ ] E3. Combustible enrichi dans le contrôleur + bouton « Démarrer » → 120 En/t par cellule ; un combustible dure 6000 ticks (5 min).
- [ ] E4. Chaleur : +4 par cellule, −3 par dissipateur (et −1) par tick ; bouton « Arrêter » → la chaleur redescend.
- [ ] E5. Trop de cellules et peu de dissipateurs : à 75 % de la limite, avertissement « ⚠ Réacteur en surchauffe » en barre d'action ; à 10 000 → explosion (puissance 6), y compris dans un territoire protégé.
- [ ] E6. Hors explosion de fusion, la protection anti-explosion du territoire reste active (TNT bloquée).

## F. Persistance et serveur dédié
- [ ] F1. Redémarrer le serveur → énergie stockée, chaleur, combustible et emplacements conservés.
- [ ] F2. Le serveur dédié démarre sans erreur ; le journal liste les recettes d'ingénierie chargées.
- [ ] F3. `/reload` avec une recette d'ingénierie invalide dans un datapack → recette ignorée avec message dans le journal, les autres restent.
