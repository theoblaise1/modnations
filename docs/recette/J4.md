# Recette en jeu — Jalon J4 (terminal, /daily, caisses, avant-postes, contrats, entreprises)

Prérequis : recettes J1 à J3 validées ; un serveur dédié (`./gradlew runServer` ou le `.jar` de la CI)
et un client ; **deux clients** pour les lignes marquées [2 joueurs] ; vous êtes opérateur. Le même `.jar`
(0.4.0-j4) doit être sur le serveur et sur chaque client. Valeurs citées = configuration par défaut ;
les montants dépendent de l'état de l'étal ou du tableau : relisez-les dans `/trade list` ou `/contract info`.

Pour aller vite, en opérateur (Tab complète les arguments) :
- `/sfadmin money give|take|set <joueur> <montant>` · `/sfadmin treasury <nation> <montant>` ·
  `/sfadmin research <nation> complete <palier>|points <n>` · `/sfadmin bypass`
- `/sfadmin terminal reset|give <joueur> [minutes]` · `/sfadmin daily reset <joueur>` · `/sfadmin daily streak <joueur> <n>`
- `/sfadmin crate givekey <joueur> <type> [nombre]` · `/sfadmin crate pity <joueur> <type> <valeur>`
- `/sfadmin outpost create <pool>|info|rotate|respawn|remove` (avant-poste le plus proche, 32 blocs au plus ;
  `<pool>` s'écrit `sovereignfrontier:general`, `…:prospecteur` ou `…:trappeur`)
- `/sfadmin contract <nation> refresh|complete <n>|expire <n>` · `/sfadmin enterprise <nation> cycle`
- Configuration rechargée à chaud (`<monde>/serverconfig/sovereignfrontier-server.toml`), à remettre ensuite :
  `[treasury] incomeIntervalTicks = 200` · `[terminal] terminalAfkSeconds = 30` · `[market] merchantRotationTicks = 1200` ·
  `[contracts] contractMinNationAgeHours = 0`

Coche chaque ligne ; note le message exact si un résultat diffère.

## A. Chargement des données (journal du serveur)

Aucune ligne « ignoré », « ignorée » ni « indisponible ».
- [ ] A2. `/reload` : mêmes lignes de publication, audit des recettes répété, aucune erreur.
- [ ] A3. Datapack de monde qui remplace `data/sovereignfrontier/crates/commune.json` par une table contenant `minecraft:netherite_ingot` → `/reload` : « Caisse sovereignfrontier:commune ignorée : objet(s) interdit(s) dans les caisses (#sovereignfrontier:interdit_caisses) : […] » ; clic droit sur une caisse commune avec sa clé → « Caisse commune indisponible : sa table est invalide (journal du serveur). » ; les 3 autres caisses fonctionnent. ## B. Terminal bancaire
- [ ] B1. Craft `IPI / GRG / III` (I lingot de fer, P panneau de verre, G lingot d'or, R bloc de redstone) → Terminal bancaire, aussi dans l'onglet créatif. Aucune nation n'est requise pour l'utiliser.
- [ ] B2. Joueur neuf, ou moins de 15 s après `/sfadmin terminal reset <joueur>`, clic droit sur le terminal → barre d'action « Terminal bancaire : rien à encaisser — jouez activement pour accumuler des crédits. »
- [ ] B3. `/sfadmin terminal give <joueur> 60` → « <joueur> : 60 minute(s) d'activité créditée(s) au barème ; épargne : 240 cr. » (de 239 à 242 selon l'activité réelle entre les commandes).
- [ ] B4. Clic droit → « Terminal bancaire : 240 cr versés sur votre portefeuille (solde : …). » ; `/balance` augmenté d'autant ; un second clic → message de B2.
- [ ] B5. Barème dégressif : `reset`, `give 30`, `give 60` (sans encaisser) puis `/terminal` (ou clic accroupi, main vide) → « Terminal bancaire — votre épargne », « Temps actif dans la fenêtre : environ 1 h 30 min (heure 2 du barème) », « Taux actuel : 180 cr/h, puis 135 cr/h dans … de jeu actif », « Épargne : 330 cr (plafond 3 000 cr) » (329 à 333), « Le barème repart à la 1re heure dans … », « Statut : actif, vos gains s'accumulent. »
- [ ] B6. Plafond : `terminalMaxPending = 100`, `reset`, `give 60` → « épargne : 100 cr » ; `/terminal` → « Épargne : 100 cr, pleine (plafond 100 cr) : encaissez-la à un Terminal bancaire. » ; barre d'action « Épargne du Terminal pleine (100 cr) : encaissez-la à un Terminal bancaire. » au plus une fois toutes les 5 min. Remettre 3000.
- [ ] B7. Inactivité : `terminalAfkSeconds = 30`, ne rien toucher 35 s → barre d'action « Inactivité détectée : vos gains du Terminal sont en pause. » (une seule fois) ; bouger la souris → « Activité détectée : vos gains du Terminal reprennent. » La commande `/terminal` compte elle-même comme activité (elle ne prouve pas la pause).
- [ ] B8. Ne comptent jamais : clic gauche ou usage d'un objet en boucle sans bouger la caméra, déplacement passif (eau, bateau, wagonnet, vol plané) → (avec `terminalAfkSeconds = 30`) le message de pause apparaît quand même et aucune reprise n'est annoncée. Casser et reposer en boucle le **même** bloc ne maintient pas l'activité.
- [ ] B9. Le terminal cassé à la pioche se récupère. Après redémarrage du serveur, l'épargne et la fenêtre sont conservées (`/terminal`).

- [ ] D5. Clic droit sur la caisse commune avec sa clé → 1 clé consommée ; message « Caisse commune : » suivi de 3 gains (objets avec quantité, ou un montant en cr) ; l'argent est versé au portefeuille ; la caisse s'ouvre (animation, particules, son).

- [ ] D7. Pitié : `/sfadmin crate pity <joueur> commune 20` → « Pitié de la Caisse commune pour <joueur> fixée à 20 (3 entrée(s) rare(s)). » ; `/crate pity` liste « 1–2 × Diamant : 20/20 · 1 × Clé industrielle : 20/20 · 500 cr à 900 cr : 20/20 » (noms vanille selon la langue). ## E. Avant-postes et commerce
- [ ] E1. Monde neuf : `/locate structure #sovereignfrontier:avant_postes` renvoie des coordonnées ; `/place structure sovereignfrontier:avant_poste_desert` pose un avant-poste (sol, 4 poteaux, toit, lanternes, caisse commune, tonneau). - [ ] E2. Au premier tick, un seul marchand apparaît derrière le comptoir, immobile, tourné vers les joueurs proches ; `/sfadmin outpost info` : « Identifiant : … — pool : sovereignfrontier:general — faction : sovereignfrontier:neutre », « Marchand présent : … », « Aucun grief enregistré. »

Le marchand est invulnérable (épée, flèche, feu, explosion) ; il ne se laisse ni pousser, ni attacher, ni monter. `/kill` le tue : `/sfadmin outpost info` → « Marchand absent ou non chargé (/sfadmin outpost respawn). » ; `/trade` (ou `/sfadmin outpost respawn`, ou clic droit sur le comptoir) le fait réapparaître.
- [ ] E4. `/summon sovereignfrontier:marchand` près du comptoir : le doublon disparaît en moins de 6 s.

- [ ] E6. Étal neuf (`/sfadmin outpost create sovereignfrontier:general`) : `/trade` → « Commerce avec : Marchand général. » ; `/trade list` affiche l'étal avec des boutons cliquables [Acheter] et [Vendre] (grisés si impossible). Protection de la boîte (en survie, sans `/sfadmin bypass`) : casser ou poser un bloc dans la boîte (7 blocs autour du comptoir en X et Z, de 2 sous à 7 au-dessus : sol, poteaux, toit) → refusé, barre d'action « Avant-poste marchand protégé : impossible de casser ou de poser des blocs ici. » ; au-delà de la boîte, c'est permis. - [ ] E15. Territoire : `/nation create` ou `/claim` dans le chunk d'un avant-poste ou l'un des 8 chunks voisins → « Ce chunk fait partie d'un avant-poste marchand : impossible de le revendiquer. » ; au-delà de ces 3 × 3 chunks, c'est accepté.

## G. Entreprises
Prérequis : nation de 3 habitants au moins, sans palier Ressources terminé (sinon +4 % par palier sur les quantités) ni bonus de revenu (sinon argent et revenu passif majorés).
- [ ] G1. `/enterprise` → « Entreprises de <nation> » ; Agricole et Minier « ○ … : aucun habitant — ×1 — 1 cr/cycle par habitant » ; Logistique « ✘ … Verrouillé : recherche « Administration municipale » requise. » ; Industriel verrouillé par « Atelier mécanique » ; pied « Habitants libres : 3 / 3 — revenu passif : 15 cr/cycle — prochain cycle dans … ».
- [ ] G2. `/enterprise info agricole` : « Domaine Ressources : +4 % par palier terminé (0 palier(s)) → ×1 », argent par habitant, produits (blé 1, carotte 0,4, pomme de terre 0,4, betterave 0,2, poudre d'os 0,3) et le cuir « — recherche « Engrais naturels » requise » ; bouton [Affecter des habitants].
